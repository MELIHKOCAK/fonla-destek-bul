# app/

Uygulama seviyesi provider, konfigürasyon ve başlangıç yardımcıları için
ayrılmış klasör. Şu an için boş tutulmaktadır; TanStack Start şablonunda
router `src/router.tsx` ve root shell `src/routes/__root.tsx` üzerinde
çalıştığı için provider'lar oraya yerleştirilir. İleride uygulama geneli
context'ler (örn. tema, i18n) burada toplanabilir.
